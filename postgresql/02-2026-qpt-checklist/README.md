# Оптимизация PostgreSQL 16: практическая памятка для курса QPT
### Структурированный и готовый к использованию чек-лист по оптимизации производительности СУБД

Данная памятка станет отличным дополнением к учебным материалам курса QPT. PostgreSQL 16. Оптимизация запросов. Все теоретические концепции, разбираемые на занятиях, теперь собраны в едином справочнике с примерами и готовыми шаблонами для настройки.

## Что внутри?

11 ключевых разделов настройки: от памяти и параллелизма до функций и управлением порядком JOIN-соединений.
* Практические SQL-примеры для некоторых параметров.
* Формулы расчёта памяти, параллельных воркеров, стоимости операций.
* Важные нюансы для разных версий PostgreSQL и ОС.
Ссылки на официальную документацию для углубленного изучения.

* Администраторы БД, которые хотят быстро находить нужные параметры
